Component library

Every token, component, and state in the system, rendered from the same stylesheets the product uses. If something here looks wrong, it is wrong everywhere. Toggle the theme in the masthead — both themes are authored, neither is an inversion of the other.

No frameworks, no libraries, no build step. Icons are hand-drawn inline SVG from assets/icons.svg; type is self-hosted WOFF2.

Privacy treatment

The verification model made visible. The obscured region is a deliberate design element, not a rendering artefact.

Obscured detail identifyingMarks is never rendered on a public page. It is the claim challenge answer, so revealing it would defeat verification entirely.

Why part of this photo is hidden

Anyone can see a photograph of a found item. Only the person who lost it can describe the detail underneath. That description is the claim challenge.
